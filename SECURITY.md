# Security Policy

## Supported Versions

This portfolio project is maintained on the latest `main` branch.

## Reporting a Vulnerability

If you identify a security issue in this repository, please do not open a public issue with exploit details. Instead:

1. Document the issue clearly.
2. Include impact, reproduction steps, and proposed mitigation.
3. Send the report privately through the contact paths listed on [Kinetic Gain](https://kineticgain.com/).

## Scope

This repository is a recruiter-ready portfolio project. It does not process production customer data or ship with live credentials.
